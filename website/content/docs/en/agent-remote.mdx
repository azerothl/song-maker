# Agent / remote

Remote GPU processing is not an available feature. The control present in some interfaces is a prototype: it still queues work locally and does not send a network request. Use the local workflow documented on this site.

## Guardrails

- The required models must be installed on the computer
- The main generation and audio processing workflow runs locally
