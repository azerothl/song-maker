# Agent / remote

Phase 4 introduces agent collaboration and a remote GPU worker (`@song-maker/remote-worker`), plus Akasha/DeclUI notes.

## Guardrails

- Personal prototype — not a multi-tenant SaaS
- Limits and permissions stay **explicit** (no silent bypass)
- Partition invariants (`@song-maker/partition-invariants`) keep score ↔ audio coherent

## What is not promised

- Guaranteed cloud availability
- Public queue
- Monetization or hosting of CC BY-NC weights

Use remote mode only when you control the worker and accept the limits documented in the app.
