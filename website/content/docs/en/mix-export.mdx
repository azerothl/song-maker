# Mix & export

## Separated tracks

The standard **HTDemucs** model separates vocals, drums, bass, and other sounds. An experimental ONNX mode also estimates guitar and piano. These tracks can contain bleed, especially piano. Results vary by song.

## Mix & production

- Edit clips and adjust track levels.
- Find the production tools in the application.
- **Grid-snapped punch:** in/out points snap to the grid; user audio clips have native `startMs`.
- **Instrumental part** from Production:
  - tempo / key / style via **YuE2** (bass, drums, accompaniment);
  - mix / stems via the opt-in **ACE-Step 1.5 Base Lego** sidecar (Python REST, not the Turbo GGUF). YuE2 does not accept `audio_input`. Lego may return a fused mix, not a dry stem. A YuE2 mix stays CC BY-NC. Lego install: [Setup](/en/docs/setup).

## Export

Export your mix as **WAV**, **FLAC**, or **MP3**. If Song Maker cannot find ffmpeg, set its path with `SONG_MAKER_FFMPEG`.
