# Mix & export

## Stems

The standard **HTDemucs** path separates vocals, drums, bass, and other. An experimental ONNX six-stem path adds estimated guitar and piano tracks. These estimates can contain leakage, especially piano, and are not guaranteed artifact-free separation. The BS-RoFormer provider included in the repository is a stub, not a ready-to-use separator.

## Mix & production

- Edit clips and adjust the mix
- Use the production tools available in the application

## Export

Export formats: **WAV**, **FLAC**, and **MP3**. If Song Maker cannot find ffmpeg, set its path with `SONG_MAKER_FFMPEG`.
