# Mix & export

## Stems

The current **HTDemucs** output defaults to four stems: vocals, drums, bass, and other. We are testing whether separation can produce more; the outcome is not yet established. The BS-RoFormer provider included in the repository is a stub, not a ready-to-use separator.

## Mix & production

- Edit clips and adjust the mix
- Use the production tools available in the application

## Export

Export formats: **WAV**, **FLAC**, and **MP3**. If Song Maker cannot find ffmpeg, set its path with `SONG_MAKER_FFMPEG`.
