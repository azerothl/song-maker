# What’s new — v0.4.1

This release fixes several Studio and Library issues:

- Projects containing only imported audio tracks are recognized as non-empty.
- Track names and order can be changed and persist when the project is reopened.
- Selected rhythmic subdivisions and track row height apply correctly in the Studio.
- The mix assistant filters settings it cannot apply and lets you adjust gain and pan before confirming.
- In the Library, only the track currently playing shows playback progress on its waveform.
- Mix assistant and empty Partition messages explain available actions more clearly.
