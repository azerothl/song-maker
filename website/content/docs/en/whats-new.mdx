# What’s new — v0.3.2

This release includes these improvements:

- **Studio:** dedicated navigation, direct creation of audio, MIDI, or AI-generated instrument tracks, denser track controls, and an always available player.
- **Library:** waveforms, playlists, favorites, and details for saved songs.
- **MIDI and instruments:** edit MIDI in the Studio and preview/render with compatible VST3 instruments.
- **YuE2:** older profiles with an absolute model path are converted to a relative path when the file is inside the model folder; paths outside that folder are rejected with a clear message.
- **Batch mode:** documentation now covers importing multiple songs, tracking takes, and resuming queued work.
