# What’s new — v0.4.3

This patch improves note extraction and moves audio/MIDI conversion into the arrangement.

## Note extraction

- Basic Pitch setup and extraction diagnostics are easier to understand.
- The generated score has a clearer issue summary and a more usable note editor, including an obvious control to play the notes.

## Audio and MIDI in the arrangement

- Convert an audio track to an editable MIDI track directly from the arrangement. The new MIDI lane appears below its source audio track.
- Render a MIDI track to audio using its selected instrument and track effects. The rendered audio lane appears below its MIDI source.
- Source tracks remain in the project, and the conversions can be undone through project history.
