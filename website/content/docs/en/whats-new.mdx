# What’s new — v0.3.0

This release gathers changes since the last published release, v0.1.1. The v0.2.0 draft did not contain every installer.

## Production and plugins

- **VST3 on Windows:** offline master effects feed both preview and export. Native plugin editor windows and MIDI-controlled VST3 instruments are available. Plugins are installed by the user. AU/macOS is not included.
- **Recording on Windows:** choose shared or exclusive WASAPI capture. Unsupported device formats return an explicit error; switch back to shared mode when needed. ASIO is not included.
- **ACE-Step Lego:** project audio is now sent for mix- or stem-conditioned parts.

## Generation and editing

- Instrumental processing reduces vocal residue and checks ACE-Step output duration before activation. A model can still leave audible residue.
- Batch jobs isolate task failures more reliably; cancellation, recovery, and recording feedback have been improved.
- YuE2 score export preserves the final chord. Production and export received additional fixes.
- The release also includes the first-launch assistant, model setup, JSON batch import, instrumental parts, grid-snapped punch, and French/English desktop UI introduced since v0.1.1.

## Install and update notes

The audio engine and model packs download separately. YuE2 requires acceptance of its CC BY-NC 4.0 license before download.

Windows installers in this release are not Authenticode-signed, and macOS apps are not notarized. Windows SmartScreen or a macOS first-launch approval may appear. Tauri updater packages remain signed. Authenticode signing and notarization are planned starting with v1.0.0.

## Limits

The VST3 host is Windows-only and renders offline. AU/macOS and real-time VST3 monitoring are not included. ASIO is not supported. YuE2 does not accept reference audio.
