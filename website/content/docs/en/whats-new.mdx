# What’s new — v0.4.0

This release includes these improvements:

- **Studio:** denser tracks, aligned gain and pan controls, and direct access to versions imported through MCP.
- **MCP — projects and library:** create, inspect, and update projects, protected deletion, and manage saved tracks and playlists in the active profile.
- **MCP — production:** import audio and completed generations, inspect and select versions, edit mixes, and render or export audio.
- **MCP — composition:** edit MIDI notes and transcribe audio to MIDI with BasicPitch.
- **MCP — generation:** YuE2 and ACE-Step tools when the required engines and consent are available; batches with multiple takes run sequentially.
- The [MCP capability matrix](https://github.com/azerothl/song-maker/blob/main/docs/mcp-capability-matrix.md) describes remaining limits and actions that still require Song Maker or the user.
