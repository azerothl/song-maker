# First song

After installing and opening Song Maker:

1. In the **Library**, create a song.
2. Enter its **style** and **lyrics**.
3. Start generation with YuE2.
4. Listen to the result, then adjust the style or seed to try another version.

You can generate a song from a style and lyrics without importing a score.

## Tips

- **Q4** is the default model setting and uses less video memory than Q8.
- Plan for prototype sessions of roughly 30 minutes or less.
- The requested duration is a target; generation does not guarantee an exact length.
- YuE2 weights use the **CC BY-NC 4.0** license, which restricts commercial use.
