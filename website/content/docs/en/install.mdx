# Install Song Maker

## 1. Download the app

Download the installer for your system:

- Windows x64: [recommended `.exe` installer](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64-setup.exe) or [`.msi`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64_en-US.msi), with an NVIDIA GPU.
- macOS: [Apple Silicon `.dmg`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___aarch64.dmg) or [Intel Mac `.dmg`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64.dmg), using Metal acceleration.
- Linux x64: [AppImage](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___amd64.AppImage), [`.deb`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___amd64.deb), or [`.rpm`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker-__APP_VERSION__-1.x86_64.rpm), with an NVIDIA GPU.

[See all releases and their files](https://github.com/azerothl/song-maker/releases/latest).

The app and models stay on your computer.

What **v0.1.2** adds: [What’s new](/en/docs/whats-new).

## 2. Open the app (setup)

On **first launch**, Song Maker’s assistant:

1. checks the GPU (NVIDIA CUDA or Metal);
2. offers the **Q4** pack (default) or **Q8**;
3. asks you to accept YuE2 **CC BY-NC 4.0** and HTDemucs licenses;
4. downloads the engine and weights (can resume if the connection drops).

No online account. Screens, Settings, Lego, and ffmpeg: [Set up Song Maker](/en/docs/setup).

Windows installers may not all be signed yet, so SmartScreen can appear. On macOS the app is not notarized; allow it in System Settings → Privacy & Security.

## 3. Disk space and ffmpeg

The engine, YuE2, and HTDemucs need **several gigabytes**. ffmpeg with libsoxr is used for resampling and some exports:

- Windows: `winget install Gyan.FFmpeg`
- macOS: `brew install ffmpeg`
- Linux: your distribution’s ffmpeg package

Otherwise set `SONG_MAKER_FFMPEG`.

## Script path (optional)

To download binaries and weights **without** the in-app assistant (developers):

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/azerothl/song-maker/main/scripts/first-run-windows.ps1 | iex
```

macOS / Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/azerothl/song-maker/main/scripts/first-run-unix.sh | bash
```

The usual path is still the assistant in the installed app.
