# Score and piano roll

User scores are a **phase 2** capability already available in the app. Find them in the **Score** (Partition) section on the project screen — expand the panel if it is collapsed.

## Capabilities

- Open the **Score** section.
- **Import MIDI** or **create a blank score**.
- Edit notes in the **piano roll** (voice, velocity, confirmed quantize, transpose, key / meter, chords).
- Export **MIDI** or preview YuE2 **ABC**, then start a generation.

## Prepare a generation

1. Open **Score**.
2. Import a MIDI file **or** create a blank score.
3. Edit in the piano roll and validate the score.
4. Preview ABC (cot ≠ off), then start audio generation.

Without a user score, phase 1 generation (style + lyrics) remains available. A generation’s captured ABC (`Partition ABC (prise)`) is separate from the editor.
