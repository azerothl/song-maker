# Score and piano roll

Song Maker lets you import a MIDI score, edit notes in the piano roll, and prepare an ABC file for YuE2.

## Capabilities

- Import a **MIDI** file.
- Edit notes in the **piano roll**.
- Check and export the score as **ABC**, the format YuE2 uses.
- Start a generation from the score.

## Prepare a generation

1. Import a MIDI file or add notes in the piano roll.
2. Check the score.
3. Export the ABC file, then start audio generation.
