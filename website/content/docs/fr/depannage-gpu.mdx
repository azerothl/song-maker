# Dépannage GPU : Q4, Q8 et mémoire vidéo

| Modèle | Mémoire vidéo indicative | Usage |
|---|---|---|
| **Q4** | Environ 8 Go ou plus, selon la carte et le contexte | Réglage par défaut pour démarrer |
| **Q8** | Environ 12 Go ou plus | Peut offrir une meilleure fidélité si la carte dispose d’assez de mémoire |

## Symptômes fréquents

- **Le test GPU se termine avec le code 2** : vérifiez que le pilote NVIDIA est installé et que `nvidia-smi` détecte la carte.
- **Mémoire insuffisante ou processus interrompu** : choisissez Q4, fermez les autres applications utilisant le GPU et gardez `max_loaded_models=1`.
- **La vérification du hash échoue** : relancez `verify-hashes`. N’utilisez pas une autre archive CUDA à la place.

## Checklist

1. Mettez à jour le pilote NVIDIA.
2. Vérifiez que l’archive CUDA correspond à votre système (Windows 12.4 ou Linux 12.8).
3. Relancez la vérification du modèle Q4.
4. Vérifiez que `health-check` réussit avant de relancer Song Maker.
