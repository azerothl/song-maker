# Mix & export

## Stems

Séparation via **HTDemucs** (et **BS-RoFormer** côté providers). Isolez voix / batterie / basse / autres avant de remixer.

## Mix & production

- Timeline de **clips**
- Overlay production : limiteur, loudness (et stubs d’automation / effets dans `@song-maker/mix-production`)

## Export

Formats livrés : **WAV**, **FLAC**, **MP3**. Vérifiez le chemin ffmpeg (`SONG_MAKER_FFMPEG` si besoin).

## LoRA

Les packs LoRA optionnels passent par une **porte CC BY-NC** explicite dans `@song-maker/lora-packs` — pas de badge de monétisation.
