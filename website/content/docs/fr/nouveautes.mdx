# Nouveautés — v0.3.1

Cette mise à jour apporte deux correctifs :

- **YuE2 :** le moteur audio reçoit le chemin du modèle GGUF sélectionné lors de l’installation (Q4 ou Q8), y compris pour les tâches isolées et batch.
- **Windows :** le moteur audio démarre sans ouvrir une fenêtre de terminal supplémentaire.
