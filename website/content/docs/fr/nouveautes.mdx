# Nouveautés — v0.1.2

Par rapport à **v0.1.1**, l’application et ce site documentent :

1. **[Génération batch](/fr/docs/generation-batch)** — fichier JSON UTF-8 dans la Bibliothèque, champs et exemple complets.
2. **[Configuration](/fr/docs/configuration)** — assistant de premier lancement, Q4/Q8, Paramètres, ffmpeg, Lego opt-in.
3. **Partie instrumentale** depuis Production (YuE2 selon le projet, ou mix/stems via Lego).
4. Punch aimanté, `startMs` natif, interface FR/EN, téléchargement YuE2 sans figer la fenêtre.

## Bibliothèque — plusieurs morceaux

**Bibliothèque → Génération batch.** Le fichier doit être du JSON UTF-8 avec `"schemaVersion": 1` et un tableau `songs`. Chaque entrée exige `id`, `title`, `style`, `lyrics`.

Les inférences restent **sérielles** (capacité GPU admise = 1). `allowReduction` (défaut) lance à 1 ; `requireRequested` bloque si vous demandez plus.

Le détail des champs, des défauts et un exemple copiable : [Génération batch](/fr/docs/generation-batch).

## Configuration

Ce n’est plus seulement « lancer un script ». Après l’installeur :

- assistant GPU / licences / pack Q4 ou Q8 / téléchargement reprisable ;
- **Paramètres → Système** pour la langue FR/EN ;
- YuE2 par défaut ; ACE-Step Turbo et Lego sont des opt-in distincts.

Guide pas à pas : [Configurer Song Maker](/fr/docs/configuration).

## Production — partie instrumentale

- **Tempo / tonalité / style (YuE2) :** basse, batterie ou accompagnement, puis import dans l’arrangement.
- **Mix / stems (opt-in) :** sidecar Python ACE-Step 1.5 **Base Lego** (pas le GGUF Turbo, pas un `audio_input` YuE2). YuE2 **refuse** une entrée audio. Lego peut produire un **mix fusionné**, pas un stem dry. Import à `start_ms = 0`. Licence MIT sur la carte ACE-Step ; un mix YuE2 reste **CC BY-NC**. GPU ≥ 12 Go VRAM conseillés.

Voir [Mix & export](/fr/docs/mix-export) et [Configuration](/fr/docs/configuration).

## Autres

- Punch aimanté sur la grille ; `startMs` natif pour les clips audio utilisateur.
- Téléchargement d’un pack YuE2 depuis Paramètres sans figer la fenêtre.
- Hôte DeclUI embarqué opt-in (`127.0.0.1`) ; la génération YuE2 reste locale.
- Interface de l’application **français / anglais** (Paramètres → Système).

Les plugins VST3 ne sont pas un produit : un spike existe derrière un flag. Le modèle maison et `audio_input` YuE2 restent indisponibles.
