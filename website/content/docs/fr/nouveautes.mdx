# Nouveautés — v0.3.2

Cette version apporte les améliorations suivantes :

- **Studio :** navigation dédiée, ajout direct de pistes audio, MIDI ou instrumentales générées par IA, réglages de pistes plus denses et lecteur toujours accessible.
- **Bibliothèque :** formes d’onde, playlists, favoris et informations des titres conservés.
- **MIDI et instruments :** édition dans le Studio et aperçu/rendu avec les instruments VST3 compatibles.
- **YuE2 :** les anciens profils dont le chemin du modèle est absolu sont convertis en chemin relatif lorsqu’ils pointent dans le dossier des modèles ; un chemin extérieur est refusé avec une explication.
- **Mode batch :** import de plusieurs titres, suivi des prises et reprise des tâches décrits dans la documentation.
