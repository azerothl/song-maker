# Premier morceau

Après avoir installé et ouvert Song Maker :

1. Dans la **Bibliothèque**, créez un morceau.
2. Renseignez son **style** et ses **paroles**.
3. Lancez la génération avec YuE2.
4. Écoutez le résultat, puis modifiez le style ou la graine pour essayer une autre version.

Vous pouvez générer un morceau à partir du style et des paroles sans importer de partition. Pour un instrumental sans texte vocal, activez le **mode instrumental** : les paroles deviennent facultatives et peuvent rester vides.

Pour plusieurs morceaux d’un coup, **Bibliothèque → Génération batch** importe un JSON UTF-8. Les prises passent par la file GPU une à une (capacité admise : 1). Détails : [Nouveautés v0.1.2](/fr/docs/nouveautes).

## Conseils

- Le modèle **Q4** est le réglage par défaut. Il demande moins de mémoire vidéo que Q8.
- Avec le prototype, prévoyez des sessions de l’ordre de 30 minutes ou moins.
- La durée choisie est indicative ; la génération ne garantit pas une longueur exacte.
