# Installer Song Maker

## 1. Télécharger l’application

Téléchargez directement l’installeur adapté à votre système :

- Windows x64 : [installeur `.exe` recommandé](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64-setup.exe) ou [`.msi`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64_en-US.msi), avec carte NVIDIA.
- macOS : [Apple Silicon `.dmg`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___aarch64.dmg) ou [Mac Intel `.dmg`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64.dmg), avec accélération Metal.
- Linux x64 : [AppImage](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___amd64.AppImage), [`.deb`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___amd64.deb) ou [`.rpm`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker-__APP_VERSION__-1.x86_64.rpm), avec carte NVIDIA.

[Voir toutes les versions et les fichiers de la release](https://github.com/azerothl/song-maker/releases/latest).

L’application et les modèles restent sur votre ordinateur. Les fichiers YuE2 et HTDemucs sont téléchargés séparément lors de la première configuration.

## 2. Installer le moteur et les modèles

Les poids YuE2 sont soumis à la licence [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/), qui restreint l’usage commercial. L’assistant vous demande votre accord avant les téléchargements. Le modèle Q4 est choisi par défaut et les téléchargements interrompus peuvent reprendre.

### Windows

Ouvrez PowerShell et collez cette commande :

```powershell
irm https://raw.githubusercontent.com/azerothl/song-maker/main/scripts/first-run-windows.ps1 | iex
```

Il faut un GPU NVIDIA compatible et un pilote récent. L’installeur n’est pas encore signé par un certificat de publication : Windows peut afficher SmartScreen.

### macOS

Ouvrez Terminal et collez :

```bash
curl -fsSL https://raw.githubusercontent.com/azerothl/song-maker/main/scripts/first-run-unix.sh | bash
```

Les Mac Intel et Apple Silicon utilisent le moteur Metal. L’application n’est pas notariée : au premier lancement, autorisez-la depuis Réglages Système → Confidentialité et sécurité si macOS le demande.

### Linux

Sur un PC x64 avec carte NVIDIA, ouvrez Terminal et collez :

```bash
curl -fsSL https://raw.githubusercontent.com/azerothl/song-maker/main/scripts/first-run-unix.sh | bash
```

Le pilote NVIDIA doit prendre en charge CUDA 12.8. L’archive publiée cible Ubuntu x64 ; les autres distributions peuvent nécessiter des dépendances système supplémentaires.

## 3. Prévoir l’espace disque

Le moteur, YuE2 et HTDemucs occupent plusieurs gigaoctets. Assurez-vous d’avoir une connexion stable et assez d’espace libre. Les fichiers sont conservés dans le cache local de Song Maker.

ffmpeg avec libsoxr est nécessaire pour le rééchantillonnage et certains exports : `winget install Gyan.FFmpeg` sous Windows, `brew install ffmpeg` sur macOS, ou le paquet ffmpeg de votre distribution Linux.
