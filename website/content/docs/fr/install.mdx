# Installer Song Maker

## 1. Télécharger l’application

Téléchargez l’installeur adapté à votre système :

- Windows x64 : [installeur `.exe` recommandé](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64-setup.exe) ou [`.msi`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64_en-US.msi), avec carte NVIDIA.
- macOS : [Apple Silicon `.dmg`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___aarch64.dmg) ou [Mac Intel `.dmg`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___x64.dmg), avec accélération Metal.
- Linux x64 : [AppImage](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___amd64.AppImage), [`.deb`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker___APP_VERSION___amd64.deb) ou [`.rpm`](https://github.com/azerothl/song-maker/releases/latest/download/Song.Maker-__APP_VERSION__-1.x86_64.rpm), avec carte NVIDIA.

[Voir toutes les versions et les fichiers de la release](https://github.com/azerothl/song-maker/releases/latest).

L’application et les modèles restent sur votre ordinateur.

Ce que change la **v0.2.0** : [Nouveautés](/fr/docs/nouveautes).

## 2. Ouvrir l’application (configuration)

Au **premier lancement**, un assistant dans Song Maker :

1. vérifie le GPU (NVIDIA CUDA ou Metal) ;
2. propose le pack **Q4** (défaut) ou **Q8** ;
3. demande l’acceptation des licences YuE2 **CC BY-NC 4.0** et HTDemucs ;
4. télécharge le moteur et les poids (reprise possible si la connexion coupe).

Ce n’est pas un compte en ligne. Détail des écrans, de Paramètres, de Lego et de ffmpeg : [Configurer Song Maker](/fr/docs/configuration).

Les installeurs Windows ne sont pas encore tous signés : SmartScreen peut s’afficher. Sur macOS, l’app n’est pas notariée : autorisez-la dans Réglages Système → Confidentialité et sécurité.

## 3. Espace disque et ffmpeg

Le moteur, YuE2 et HTDemucs occupent **plusieurs gigaoctets**. ffmpeg avec libsoxr sert au rééchantillonnage et à certains exports :

- Windows : `winget install Gyan.FFmpeg`
- macOS : `brew install ffmpeg`
- Linux : paquet ffmpeg de la distribution

Sinon : variable `SONG_MAKER_FFMPEG`.

## 4. Ensuite

- [Premier morceau](/fr/docs/premier-morceau) — un style, des paroles, YuE2.
- [Génération batch](/fr/docs/generation-batch) — JSON de plusieurs morceaux.
- [Dépannage GPU](/fr/docs/depannage-gpu) — Q4, Q8, mémoire.

## Chemin scripts (optionnel)

Pour télécharger binaires et poids **sans** passer par l’assistant de l’app (développeurs) :

Windows (PowerShell) :

```powershell
irm https://raw.githubusercontent.com/azerothl/song-maker/main/scripts/first-run-windows.ps1 | iex
```

macOS / Linux :

```bash
curl -fsSL https://raw.githubusercontent.com/azerothl/song-maker/main/scripts/first-run-unix.sh | bash
```

Le parcours normal reste l’assistant dans l’application installée.
