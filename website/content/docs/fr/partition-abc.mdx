# Partition et piano roll

Song Maker permet d’importer une partition MIDI, de modifier les notes dans le piano roll et de préparer un fichier ABC pour YuE2.

## Capacités

- Importez un fichier **MIDI**.
- Modifiez les notes dans le **piano roll**.
- Vérifiez puis exportez la partition au format **ABC** utilisé par YuE2.
- Vous pouvez ensuite lancer une génération à partir de cette partition.

## Préparer une génération

1. Importez un MIDI ou ajoutez des notes dans le piano roll.
2. Vérifiez la partition.
3. Exportez le fichier ABC, puis lancez la génération audio.
