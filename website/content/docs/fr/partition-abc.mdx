# Partition et piano roll

La partition utilisateur est une capacité **phase 2** déjà disponible dans l’app. Elle se trouve dans la section **Partition** de l’écran projet (ouvrez le panneau si besoin).

## Capacités

- Ouvrez la section **Partition**.
- **Importez un MIDI** ou **créez une partition vide**.
- Modifiez les notes dans le **piano roll** (voix, vélocité, quantification confirmée, transposition, tonalité / mesure, accords).
- Exportez en **MIDI** ou prévisualisez l’**ABC** YuE2, puis lancez une génération.

## Préparer une génération

1. Ouvrez **Partition**.
2. Importez un MIDI **ou** créez une partition vide.
3. Éditez dans le piano roll, vérifiez la partition.
4. Prévisualisez l’ABC (cot ≠ off), puis lancez la génération audio.

Sans partition utilisateur, la génération phase 1 (style + paroles) reste disponible. La prise ABC d’une génération (`Partition ABC (prise)`) est distincte de l’éditeur.
