# Génération locale

Le contrôle de génération distante est un prototype : il place le travail dans la file locale et n’envoie aucune requête réseau. La génération et le traitement audio du parcours principal s’effectuent sur votre ordinateur, avec les modèles installés localement.

Pour commencer, installez le moteur audio et les modèles en suivant le guide d’installation.
