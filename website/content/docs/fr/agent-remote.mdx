# Génération locale (défaut)

La génération et le traitement audio du parcours principal s’effectuent sur votre ordinateur, avec les modèles installés localement.

Un **worker GPU distant** est disponible en opt-in (phase 4) : il faut une URL qui implémente le [contrat HTTP](https://github.com/azerothl/song-maker/blob/main/docs/remote-worker-contract.md) et un jeton partagé. Le dépôt livre un worker de référence (`packages/remote-worker-server`). Sans opt-in, **aucun** appel réseau n’est émis. Un échec distant ne démarre pas automatiquement une génération locale.

Pour commencer en local, installez le moteur audio et les modèles en suivant le guide d’installation.
