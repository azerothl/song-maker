# Agent / remote

Le mode worker distant n’est pas une fonctionnalité disponible. Le contrôle présent dans certaines interfaces est un prototype : il place encore le travail dans la file locale et n’envoie aucune requête réseau. Utilisez le parcours local documenté dans ce site.

## Garde-fous

- Les modèles nécessaires doivent être installés sur la machine
- La génération et le traitement du parcours principal s’exécutent localement
