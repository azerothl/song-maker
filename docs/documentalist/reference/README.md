# Song Maker

Song Maker est une application desktop locale pour générer, séparer, éditer et mixer des morceaux. Elle utilise notamment YuE2 pour la génération et HTDemucs pour la séparation.

## Modèles et projets

Un projet correspond à un morceau. La disponibilité des modèles, l’espace disque et les capacités GPU dépendent de la plateforme. Consulter les instructions d’installation avant de télécharger les modèles. Le Studio regroupe les pistes, l’édition et l’export.
