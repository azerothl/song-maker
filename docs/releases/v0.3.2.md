# Song Maker v0.3.2

## Français

- Refonte du parcours autour de **Bibliothèque**, **Projets**, **Studio** et **Créer**, avec un lecteur persistant et l’ajout direct de pistes audio, MIDI ou générées par IA.
- Bibliothèque enrichie avec formes d’onde, playlists, favoris et informations sur les titres conservés.
- Édition MIDI dans le Studio et prise en charge des instruments VST3 compatibles pour l’aperçu et le rendu hors ligne.
- Correction YuE2 : les anciens profils contenant un chemin absolu vers un GGUF situé dans le dossier des modèles sont normalisés avant le démarrage du moteur. Les chemins extérieurs au dossier restent refusés.
- Documentation du mode batch et des parcours MCP mise à jour.

## English

- Reworked navigation around **Library**, **Projects**, **Studio**, and **Create**, with a persistent player and direct creation of audio, MIDI, or AI-generated instrument tracks.
- Expanded Library with waveforms, playlists, favorites, and saved-song details.
- MIDI editing in Studio and compatible VST3 instruments for preview and offline rendering.
- YuE2 fix: older profiles with an absolute GGUF path inside the model folder are normalized before the engine starts. Paths outside the model folder remain rejected.
- Updated batch-mode and MCP workflow documentation.
