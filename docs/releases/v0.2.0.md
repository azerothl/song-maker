# Song Maker v0.2.0

Install the desktop app for Windows, macOS, or Linux using the matching asset below.

Song Maker downloads YuE2 and HTDemucs model files separately on first setup. They require several gigabytes of free disk space. Generation requires NVIDIA CUDA on Windows/Linux or Apple Metal on macOS. Guide: https://website-ten-iota-41.vercel.app/en/docs/install

## What’s new

- **Library batch import.** Import a UTF-8 JSON file of several songs, preview takes, then run them through the existing exclusive GPU queue. Admitted parallelism is **1** until two isolated audiocpp workers are measured. `allowReduction` starts at 1; `requireRequested` blocks a higher demand. This is not overlapping GPU inference.
- **Mix/stems add-track (opt-in).** From Production, ACE-Step 1.5 Base Lego (Python REST sidecar, not the Turbo GGUF) can add a part conditioned on the mix/stems. YuE2 still refuses `audio_input`. Lego may return a fused mix, not a dry isolated stem. MIT on the ACE-Step card; a YuE2 mix stays CC BY-NC.
- **Project-conditioned instrumental (YuE2).** Production can generate bass / drums / accompaniment from the project’s tempo, key, and style, then place it in the arrangement.
- **Native clip punch.** Snap punch in/out to the grid; native `startMs` on user audio clips.
- **YuE2 pack download.** Installing a YuE2 pack from Settings no longer freezes the window.
- **Embedded DeclUI host (opt-in).** Localhost loopback from Settings; YuE2 generation stays on the desktop.
- Desktop UI is **French and English** (Settings → System).

VST3 hosting is still a flagged spike, not a product feature. Overlapping GPU batch inference is not claimed.

## Nouveautés

- **Import batch (Bibliothèque).** Fichier JSON UTF-8, aperçu, file persistante. Les prises passent par la file GPU exclusive. Capacité **admise = 1** tant que deux workers `audiocpp` isolés n’ont pas été mesurés. `allowReduction` lance à 1 ; `requireRequested` bloque. Ce n’est pas un chevauchement d’inférence.
- **Ajout de piste mix/stems (opt-in).** Depuis Production, ACE-Step 1.5 Base Lego (sidecar Python REST, pas le GGUF Turbo) peut ajouter une partie conditionnée par le mix/stems. YuE2 refuse toujours `audio_input`. Lego peut renvoyer un mix fusionné, pas un stem dry. Carte ACE-Step MIT ; un mix YuE2 reste CC BY-NC.
- **Partie instrumentale YuE2.** Depuis Production : basse / batterie / accompagnement selon tempo, tonalité et style, puis import dans l’arrangement.
- **Punch aimanté.** Accrochage à la grille ; `startMs` natif sur les clips audio utilisateur.
- **Téléchargement YuE2.** L’installation d’un pack depuis Paramètres ne fige plus la fenêtre.
- **Hôte DeclUI embarqué (opt-in).** Loopback localhost depuis Paramètres ; la génération YuE2 reste sur le bureau.
- Interface de l’app **FR / EN** (Paramètres → Système).

L’hôte VST3 reste un spike derrière flag, pas une fonction produit. Le parallélisme GPU du batch n’est pas annoncé.
