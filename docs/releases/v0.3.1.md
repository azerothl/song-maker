# Song Maker v0.3.1

## Français

Cette mise à jour corrige deux problèmes du moteur audio :

- **YuE2** : Song Maker transmet au moteur le fichier GGUF choisi lors de l’installation (Q4 ou Q8), y compris pour les tâches isolées et batch.
- **Windows** : le moteur audio est lancé sans ouvrir de fenêtre de terminal supplémentaire.

## English

This update fixes two audio engine issues:

- **YuE2**: Song Maker passes the GGUF file selected during setup (Q4 or Q8) to the engine, including isolated and batch tasks.
- **Windows**: the audio engine starts without opening an extra terminal window.
