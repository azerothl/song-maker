# Song Maker v0.4.3

## Français

Cette version patch intègre les améliorations de la PR [#459](https://github.com/azerothl/song-maker/pull/459).

- Préparation de Basic Pitch et messages de diagnostic d’extraction plus compréhensibles.
- Récapitulatif des problèmes de partition plus clair et lecture des notes générées plus visible dans l’éditeur.
- Conversion d’une piste audio en piste MIDI éditable depuis l’arrangement ; la piste MIDI est insérée sous sa source audio.
- Rendu d’une piste MIDI en audio avec l’instrument et les effets de la piste ; le rendu est inséré sous sa source MIDI.
- Les pistes sources restent dans le projet et les conversions peuvent être annulées depuis l’historique.

Installez le fichier adapté à votre système parmi les assets ci-dessous. [Guide d’installation](https://website-ten-iota-41.vercel.app/fr/docs/install).

## English

This patch release includes the improvements from [PR #459](https://github.com/azerothl/song-maker/pull/459).

- Clearer Basic Pitch setup and note-extraction diagnostics.
- A clearer score issue summary and a more visible way to play generated notes in the editor.
- Convert an audio track to an editable MIDI track from the arrangement; the MIDI lane is inserted below its audio source.
- Render a MIDI track to audio with its selected instrument and track effects; the rendered lane is inserted below the MIDI source.
- Source tracks remain in the project, and conversions can be undone from project history.

Install the matching asset below. [Installation guide](https://website-ten-iota-41.vercel.app/en/docs/install).
